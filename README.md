# Telegram Photo Counter Bot V2

Бот для группового Telegram-чата: участники отправляют фото, бот переотправляет их от своего имени с компактной подписью `№127 · Иван Петров`, хранит статистику в JSON и даёт администратору управление в личке.

## Что нового в V2

- Админ-панель в личном чате с ботом (`/admin`).
- Расширенная статистика: сегодня, неделя, месяц, общий рейтинг, личное место и отрыв до следующего места.
- Общие milestones по общему числу фотографий.
- Milestone может быть текстом, фото или фото с подписью.
- Личные достижения пользователей по их персональному числу фото; поддерживаются `{name}` и `{count}`.
- Редактирование приветствия, инструкции и шаблона подписи к фото без изменения кода.
- Автоматические резервные копии `state.json` перед удалением фото и изменением настроек.
- Ручное создание и скачивание последней резервной копии из админ-панели.
- Совместимость со старым V1 `state.json`: существующие фото, пользователи и текстовые milestones сохраняются.

## Основная механика

1. Пользователь отправляет фото в группу.
2. Бот отправляет то же фото через Telegram `file_id` с подписью `№N · Имя`.
3. Исходное сообщение пользователя удаляется.
4. Фото добавляется в JSON и увеличивает личный счёт пользователя.
5. При достижении общего или личного порога бот отправляет настроенный milestone.

Сами изображения на Bothost не сохраняются.

## Команды пользователей

- `/me` — личный результат, место в рейтинге и сколько фото до следующего места.
- `/top` — общий рейтинг.
- `/today` — статистика за сегодня.
- `/week` — статистика за текущую неделю.
- `/month` — статистика за текущий месяц.
- `/total` — общее число действующих фото.
- `/info` — пользовательская инструкция.
- `/help` — список команд.

## Админ-панель

Откройте личный чат с ботом и отправьте `/admin`.

Разделы:

- `📊 Статистика` — сводные числа.
- `🎉 Milestones` — добавить/заменить/удалить общий порог.
- `🏅 Личные достижения` — добавить/заменить/удалить персональный порог.
- `✏️ Тексты бота` — приветствие, инструкция, шаблон подписи.
- `🗑 Удалить фото` — удаление по номеру с перенумерацией всех последующих.
- `💾 Резервные копии` — создать или скачать последнюю копию JSON.

Для добавления milestone через панель сначала вводится число, затем можно отправить:

- обычный текст;
- фотографию без подписи;
- фотографию с подписью.

Для личного достижения в тексте доступны переменные:

```text
{name} — имя пользователя
{count} — его текущее количество фото
```

Пример:

```text
🎉 {name} отправил уже {count} фото!
```

## Старые команды администратора

Оставлены для совместимости:

- `/deletephoto 146`
- `/milestones`
- `/addmilestone 100 Соточка!`
- `/editmilestone 100 Новый текст`
- `/delmilestone 100`

Фото для milestone удобнее добавлять через админ-панель.

## Удаление и перенумерация

Если было 150 фото и удалить №146:

```text
№147 → №146
№148 → №147
№149 → №148
№150 → №149
```

Следующее фото станет №150. Личный счёт автора удалённого фото уменьшается на 1. Уже сработавшие milestones и личные достижения повторно не срабатывают после такого отката.

## Тексты бота

Шаблон подписи по умолчанию:

```text
№{number} · {name}
```

Если редактировать его через панель, `{number}` и `{name}` должны остаться в тексте.

## Резервные копии

Файлы хранятся в `/app/data/backups/`.

Автокопия создаётся перед:

- удалением фотографии;
- добавлением/изменением/удалением milestones;
- изменением личных достижений;
- изменением текстов бота.

Число хранимых копий задаётся `BACKUP_KEEP` (по умолчанию 20). Старые копии автоматически удаляются.

## Переменные окружения

```text
BOT_TOKEN=...
DATA_FILE=/app/data/state.json
ADMIN_IDS=123456789
BOT_TZ=Asia/Yekaterinburg
BACKUP_KEEP=20
```

`ADMIN_IDS` необязателен: администраторы Telegram-группы тоже распознаются автоматически.

`BOT_TZ` используется для `/today`, `/week`, `/month`. Для Перми рекомендуется `Asia/Yekaterinburg`.

## Права Telegram

Бот должен быть администратором группы и иметь возможность:

- отправлять сообщения и фото;
- удалять сообщения;
- редактировать подписи собственных сообщений.

У участников можно запретить обычный текст, оставив разрешённой отправку фотографий.

Рекомендуется отключить Privacy Mode у бота в BotFather (`/setprivacy` → Disable).

## Docker / Bothost

Dockerfile уже включён. Приложение работает через long polling и публичный HTTP-порт ему не нужен.

Важно: `/app/data` должен быть постоянным volume/disk. Иначе при пересоздании контейнера `state.json` и резервные копии могут исчезнуть.

Локально:

```bash
docker build -t photo-counter-bot-v2 .
docker run --rm --env-file .env -v "$(pwd)/data:/app/data" photo-counter-bot-v2
```

## Обновление с V1

Перед обновлением рекомендуется скачать текущий `state.json` или сделать резервную копию. После запуска V2 старый формат автоматически дополняется новыми полями; существующая статистика не обнуляется.
