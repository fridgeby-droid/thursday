# Photo Counter Bot v2.2

Telegram-бот для группового фото-чата. Пользователь отправляет фото, бот удаляет исходное сообщение и публикует фото от своего имени с подписью вида `№127 · Иван Петров`. Статистика хранится в JSON.

## Основные функции

- сквозная нумерация фотографий;
- личная статистика пользователей;
- `/top`, `/me`, `/today`, `/week`, `/month`, `/total`;
- удаление фото с перенумерацией последующих сообщений;
- общие milestone: текст, фото или фото + подпись;
- личные достижения: текст, фото или фото + подпись;
- админ-панель в личном чате `/admin`;
- редактирование текстов бота;
- автоматические и ручные резервные копии JSON;
- ручная установка номера следующего фото;
- восстановление статистики по старым сообщениям через JSON-экспорт Telegram Desktop.

## Нумерация

В `/admin` → `🔢 Нумерация` администратор может задать номер, который получит **следующее** фото.

Пример: если задать `500`, следующая фотография станет `№500`, затем `№501`, `№502` и т. д. Уже опубликованные сообщения при изменении настройки не переименовываются.

Также доступна резервная команда:

```text
/setcounter 500
```

Если удалить учтённое фото, все учтённые фотографии с большим номером сдвигаются на 1 назад, а номер следующего фото также корректируется.

## Восстановление статистики из истории Telegram

Telegram Bot API не позволяет боту самостоятельно запросить старую историю группы. Поэтому восстановление выполняется через экспорт Telegram Desktop:

1. Откройте нужную группу в Telegram Desktop.
2. Экспортируйте историю чата в формате **JSON**.
3. Откройте бота в личке.
4. `/admin` → `♻️ Восстановление`.
5. Отправьте боту файл `result.json`.

Бот ищет старые сообщения с подписями вида:

```text
№127 · Иван Петров
```

и восстанавливает:

- номер фотографии;
- имя автора из подписи;
- дату сообщения;
- Telegram `message_id` сообщения бота;
- общий рейтинг;
- личные счётчики;
- номер следующей фотографии.

Перед восстановлением автоматически создаётся backup текущего `state.json`.

### Ограничение восстановления

Старые фотографии были переопубликованы **от имени бота**, поэтому в истории Telegram нет исходного Telegram ID пользователя. Восстановленные записи временно связываются с именем (`Иван Петров`). Когда пользователь отправит новое фото или вызовет `/me`, бот автоматически привяжет восстановленный счёт к его реальному Telegram ID, если имя совпадает.

## Переменные окружения

```env
BOT_TOKEN=123456:ABCDEF
DATA_FILE=/app/data/state.json
BOT_TZ=Asia/Yekaterinburg
BACKUP_KEEP=20
ADMIN_IDS=123456789
```

`ADMIN_IDS` необязателен, если администратор уже является администратором рабочей Telegram-группы.

## Docker / Bothost

Сборка рассчитана на запуск через Dockerfile. Для сохранения статистики `/app/data` должен быть постоянным томом.

При обновлении версии **не удаляйте `/app/data/state.json`**.

## V2.4 — восстановление старых фото без подписи

В разделе **Админ → Восстановление** можно загрузить `result.json` из Telegram Desktop.
Бот восстанавливает:

- уже пронумерованные фото с подписью `№127 · Имя`;
- более старые обычные фотографии без подписи;
- автора и дату старых фото из Telegram-экспорта;
- личную статистику участников;
- следующую нумерацию.

Если в экспорте есть уже пронумерованные фотографии, они используются как якоря нумерации. Старые фото без подписи получают номера по хронологии так, чтобы существующие номера не менять. Если пронумерованных фото нет, восстановленная нумерация начинается с №1.

Для полноценного восстановления при экспорте Telegram Desktop нужно включить сообщения и фотографии/медиа.
